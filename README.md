# 卡牌游戏（优化版）

这是一个无需构建工具的静态网页游戏，可直接部署到 GitHub Pages 或任意静态文件服务器。

## 运行

推荐通过本地静态服务器打开，以获得与线上部署一致的资源加载行为：

```bash
npx serve .
```

也可以直接打开 `index.html`。游戏运行时会从 `assets/` 加载样式、脚本和头像。

## 目录结构

```text
index.html              页面结构
assets/css/game.css     界面样式与动画
assets/js/game.js       游戏规则、AI、渲染、音效和管理工具
assets/avatars/         玩家头像
```

## 验证

JavaScript 可用 Node.js 做基础语法检查：

```bash
node --check assets/js/game.js
```

项目不依赖第三方 JavaScript 包，也没有编译步骤。页面会联网加载 Google Fonts；无法联网时会自动使用系统中文字体。

## 本版体验优化

- 真人与 AI 出牌会从对应位置飞向牌桌中央，并带有落牌回弹反馈。
- 回合阶段切换和可出牌按钮提供更清晰、克制的动态提示。
- 手机端将手牌调整到操作区上方，按钮采用双行拇指友好布局。
- 横屏矮屏模式压缩非关键区域，尽量保留牌桌和手牌可视空间。
- 手牌支持横向滚动吸附，并继续兼容系统“减少动态效果”偏好。
